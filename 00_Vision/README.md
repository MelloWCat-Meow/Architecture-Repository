# 00_Vision

Folder ini berisi arah produk **EduLink Tutor**, pihak-pihak yang berkepentingan, dan kesepakatan kerja tim. Isinya menjadi pegangan untuk seluruh folder lain di repositori arsitektur ini.

| No | Dokumen | Isi singkat | Penanggung jawab |
|:-:|---|---|---|
| 1 | [Vision v1.0](01_Vision.md) | Pernyataan visi, masalah, nilai, lingkup MVP, tiga KPI, prioritas MoSCoW, dan konsep solusi | CEO / PO |
| 2 | [Stakeholder](02_Stakeholder.md) | Katalog 12 stakeholder, Power/Interest Matrix, dan strategi pelibatan | CEO / PO |
| 3 | [Team Charter](03_Team_Charter.md) | Tujuan tim, susunan peran, cara kerja, jadwal sprint, dan matriks Definition of Done | CEO / PO bersama seluruh tim |

## Konteks singkat

| Keterangan | Isi |
|---|---|
| Mata kuliah | Arsitektur Sistem Perusahaan, kelas R001 |
| Kegiatan | Sprint Akhir P13 sampai P16 (empat minggu) |
| Produk | EduLink Tutor, marketplace guru les privat PT EduLink Teknologi Indonesia |
| Status produk | MVP (Minimum Viable Product, versi awal yang sudah dapat digunakan untuk fungsi intinya) |
| Sumber | Laporan Tugas Akhir "Perancangan Arsitektur Enterprise Menggunakan TOGAF ADM pada PT. EduLink Teknologi Indonesia" dan laporan Sprint Akhir tim |

## Urutan pembacaan

Dokumen disarankan dibaca dengan urutan berikut.


1. **Vision**, untuk memahami masalah, nilai, dan batas MVP.
2. **Stakeholder**, untuk mengetahui pihak yang terdampak beserta strategi pelibatannya.
3. **Team Charter**, untuk mengetahui cara kerja tim dan batasan suatu pekerjaan dinyatakan selesai.

Model bisnis (Business Model Canvas) ada di folder [`01_Business`](../01_Business/).
